簡易版・Google Apps Script

在 LINE 裡用你自己的 AI

做完之後，你會有一個只屬於你的 LINE 機器人。背後是你選的 AI：ChatGPT、Gemini 或 Claude。它能回答問題、看照片、把海報或會議通知加進 Google 行事曆，也能查你某天的行程。

  • 約 30–40 分鐘
  • LINE 與 Google 免費
  • 只付 AI 用量
  • 建議用電腦操作

1

建立 LINE 官方帳號，拿到金鑰

這個帳號就是你的機器人，金鑰讓程式能替它回話。

  1. 用電腦打開 LINE Developers，用你的 LINE 帳號登入。
  2. 第一次進來會請你建立一個 Provider，名稱隨意，例如「我的助理」。
  3. 在 Provider 裡點 Create a new channel，選 Messaging API。
  4. 畫面會說現在不能直接在這裡建立。點綠色按鈕 Create a LINE Official Account。
  5. 照表單填寫。帳號名稱就是機器人的名字，不用申請認證。
  6. 完成後點 前往 LINE Official Account Manager，同意條款。
  7. 在 Official Account Manager 點 設定 → Messaging API → 啟用 Messaging API，選剛剛建立的 Provider，其他欄位留空，按確定。
  8. 回到 LINE Developers，點進剛出現的頻道 → Messaging API 分頁 → 捲到最下面的 Channel access token → 按 Issue。
  9. 把這串很長的文字複製起來先放著，第 5 步要用。
這串 token 等於機器人的鑰匙。不要貼給任何人，也不要貼到群組。

最後關掉 LINE 內建的自動回覆，不然它會跟 AI 搶著回話：Official Account Manager → 設定 → 回應設定，把「加入好友的歡迎訊息」和「自動回應訊息」都關掉。

2

拿一把 AI 金鑰（三選一）

不知道選哪個，就先選 Gemini：免費就能開始用，不用綁卡。

Gemini（Google）ChatGPT（OpenAI）Claude（Anthropic）
費用有免費額度，不用綁卡要先儲值，最少 5 美元要先儲值
申請網址Google AI StudioOpenAI PlatformClaude Console
第 5 步填geminiopenaiclaude
  1. 打開申請網址，登入。
  2. 建立一把 API key，複製起來先放著。
  3. 選 ChatGPT 或 Claude 的話，要先到網站的 Billing（帳單）頁儲值，金鑰才能用。

一般聊天的用量很小，大多數人一個月花不到幾十元台幣。

Gemini 免費方案的對話內容，Google 可能拿去改進他們的產品。會傳工作文件、學生或客戶資料的話，改用付費方案，或選另外兩家。
AI 金鑰也不要給任何人。被別人拿到，他就能花你的錢。
3

建立 Apps Script 專案，貼上程式

程式跑在你自己的 Google 帳號裡，機器人讀寫的就是這個帳號的行事曆。

  1. 打開 Google Apps Script，用你的 Gmail 登入。
  2. 點左上角 新專案。
  3. 點左上角「未命名的專案」，改個名字，例如「LINE AI 助理」。
  4. 打開 程式碼 Code.gs，全選（Ctrl+A 或 ⌘+A）後複製。
  5. 回到 Apps Script，把編輯器裡原本的幾行全部刪掉，貼上剛剛複製的程式。
  6. 按存檔（Ctrl+S 或 ⌘+S）。
4

設定時區

時區跟 Google 行事曆一樣，行程時間才不會差幾小時。

點左邊齒輪 專案設定，時區 選「(GMT+08:00) 台北」。不在台灣的話，選你所在的時區。

5

填入金鑰

金鑰存在 Apps Script 的「指令碼屬性」裡，不會出現在程式碼中。

還在 專案設定 頁，捲到最下面的 指令碼屬性 → 編輯指令碼屬性，新增這三筆，再按 儲存指令碼屬性。屬性名稱可以按「複製」直接貼上。

LINE_CHANNEL_ACCESS_TOKEN值：第 1 步複製的 LINE token
AI_PROVIDER值：gemini、openai 或 claude（小寫）
AI_API_KEY值：第 2 步複製的 AI 金鑰
想指定模型的話，可以再加一筆 AI_MODEL。不加就用預設：Gemini 用 gemini-3.8-flash，ChatGPT 用 gpt-6-luna，Claude 用 claude-sonnet-5-5。
6

執行 setup，完成授權

讓程式可以讀寫你的行事曆、連到 AI。

  1. 回到左邊 編輯器（< > 圖示）。
  2. 上方工具列的函式選單選 setup，按 執行。
  3. 跳出「需要授權」→ 審查權限 → 選你的 Gmail 帳號。
  4. 出現「Google 尚未驗證這個應用程式」時，點左下 進階 → 前往「LINE AI 助理」（不安全）。
  5. 按 允許。
  6. 下方「執行紀錄」出現 ✅ 設定齊全 就成功了。出現 ❌ 的話，照它說的補上缺的設定，再執行一次。
「尚未驗證」是因為這支程式是你自己建的，Google 沒審查過，屬於正常現象。程式只會碰你自己的行事曆。
7

部署

部署後會拿到一個網址，LINE 的訊息就從這個網址送進來。

  1. 右上角 部署 → 新增部署作業。
  2. 左邊齒輪選 網頁應用程式。
  3. 執行身分選 我，誰可以存取選 所有人。
  4. 按 部署。
選「所有人」是為了讓 LINE 送得進來。程式會檢查網址裡的密碼，也只回應你本人，別人拿到網址也用不了。
8

把網址貼到 LINE

告訴 LINE：有人傳訊息給機器人時，送到這裡。

  1. 回到編輯器，函式選單選 showWebhookUrl，按 執行。
  2. 執行紀錄會印出一串網址，結尾是 /exec?key= 加一串亂碼。整串複製。
  3. 到 LINE Developers → 你的頻道 → Messaging API 分頁。
  4. Webhook URL 點 Edit，貼上網址，按 Update。
  5. 把 Use webhook 打開。
  6. Webhook redelivery 保持關閉。
旁邊的 Verify 按了會顯示錯誤（302），這是正常的，不用理它。Apps Script 的回應方式跟 LINE 預期的不同，但訊息實際上都收得到。
9

加好友、綁定自己

第一個傳訊息的人會成為主人，之後只有主人能用。

  1. Messaging API 分頁上方有 QR code，用手機 LINE 掃描、加好友。
  2. 傳一則訊息給它，例如「你好」。
  3. 收到「👋 綁定完成！」就好了。別人加好友傳訊息，只會收到「私人助理」的回覆。
一定要你自己傳第一則訊息。

試試看傳這些：

  • 幫我想三個週末可以帶小孩去的地方
  • （傳一張活動海報）→ 點「加到行事曆」
  • 明天有什麼行程？
  • 新對話（清掉前面的對話，重新開始）

出問題時

先在編輯器執行 checkSettings，執行紀錄會告訴你 LINE 金鑰、AI 金鑰、主人綁定是否正常。

狀況怎麼辦
傳訊息完全沒反應檢查 Webhook URL 是不是整串貼上、結尾是 /exec?key= 加一串亂碼；Use webhook 有沒有打開；部署時「誰可以存取」是不是「所有人」。
回「AI 金鑰不能用」重新複製金鑰，更新指令碼屬性 AI_API_KEY。
回「餘額不足」到 AI 公司網站的 Billing 頁儲值。
行程時間差幾小時第 4 步的時區，設成跟 Google 行事曆一樣。
想換人當主人執行 resetOwner，再用新的 LINE 帳號傳訊息。
想換 AI 公司改指令碼屬性 AI_PROVIDER 和 AI_API_KEY，不用重新部署。
有新版程式時：貼上新程式、存檔後，一定要到「部署 → 管理部署作業 → 編輯 → 版本選『新版本』→ 部署」。只存檔的話，LINE 用到的還是舊版。網址不會變，不用重貼到 LINE。

隱私

  • 程式跑在你自己的 Google 帳號裡，對話與行程不會經過作者或任何第三方。
  • 你傳的訊息與照片，會送到你選的 AI 公司處理，依各家的隱私條款處理。
  • 對話記憶只存在 Apps Script 的快取，30 分鐘沒說話就自動消失。
